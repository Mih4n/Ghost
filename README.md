# Ghost

Отчёты на Typst по методичке ГГТУ им. П. О. Сухого № 4334 и ГОСТ: лабораторные
и курсовые работы. Титульный лист, задание, реферат, содержание, нумерация
рисунков, таблиц и формул по разделам, приложения и список источников
собираются сами.

## Установка

```bash
# typst: https://typst.app/open-source/#download или пакетный менеджер
cargo install typship

git clone https://github.com/mih4n/ghost
cd ghost
typship install mih4n

# обновление
git pull
typship install mih4n
```

Версии ставятся рядом: отчёты на `@mih4n/ghost:1.0.0` продолжают собираться
как раньше.

## Начало работы

```typst
#import "@mih4n/ghost:2.0.0": *

#show: ghost.with(
  kind: "course",                         // "lab" или "course"
  discipline: [Базы данных],
  theme: [Учёт договоров с поставщиками],
  student: "Лосев М. А.",
  group: "ИТП-21",
  supervisor: ("Асенчик О. Д.", "доцент"),
  task: image("task.pdf"),                // лист задания с подписями
  abstract: [Текст реферата.],
  keywords: ("база данных", "договор", "SQL"),
  abbreviations: ("СУБД": [система управления базами данных]),
)

= Введение
= Анализ предметной области
== Постановка задачи
= Заключение
```

Полные примеры: [`examples/course.typ`](examples/course.typ) и
[`examples/lab.typ`](examples/lab.typ).

### Параметры `ghost`

| Параметр | По умолчанию | Что задаёт |
|---|---|---|
| `kind` | `"lab"` | `"lab"`: без содержания, разделы подряд. `"course"`: содержание, каждый раздел с новой страницы |
| `number` | `none` | номер лабораторной работы |
| `discipline`, `theme` | `none` | дисциплина и тема на титульном листе |
| `student`, `group` | `none` | студент и группа |
| `supervisor` | `(none, none)` | `("Фамилия И. О.", "должность")` |
| `faculty`, `department`, `specialty` | ФАИС, «Информационные технологии», 6-05-0611-01 | шапка титульного листа, специальность только у курсовой |
| `city`, `year` | `"Гомель"`, текущий год | низ титульного листа |
| `task` | `none` | страницы задания после титульного: `image("task.pdf")` или массив `image("task.pdf", page: n)` |
| `abstract`, `keywords` | `none`, `()` | реферат; объём работы (страницы, рисунки, таблицы, источники, приложения) считается сам |
| `abbreviations` | `none` | словарь сокращений: русские по алфавиту, затем латинские |
| `outline` | у курсовой `true` | содержание |
| `draft` | `false` | помечает на полях рисунки, таблицы и приложения без ссылок и источники без цитирования |

## Что делается само

- A4, поля 30/10/20/20 мм, Times New Roman 14 pt, 40 ± 3 строки на странице,
  абзацный отступ 1,25 см, выравнивание по ширине, переносы (кроме заголовков).
- Номера страниц справа внизу, 12 pt: у лабораторной со второй страницы, у
  курсовой со второго листа содержания.
- Заголовки `1`, `1.1`, `1.1.1` без точки на конце; раздел прописными, номер
  пункта полужирным курсивом, пустая строка до и после.
- `= Введение` и `= Заключение` без номера, прописными и по центру.
- Списки: `-` даёт «–», `+` даёт «а)», вложенный «1)».
- Латиница в тексте курсивом, в коде прямо.

## Рисунки, таблицы, формулы

```typst
Схема показана на рисунке @er-diagram.

#picture(image("img/er-diagram.png", width: 70%), [ER-диаграмма базы данных])

Данные приведены в таблице @data.

#tbl(table(columns: 2, [Параметр], [Значение], [a], [1]), [Исходные данные], name: "data")

Система описывается уравнением @w.

#formula($ W(s) = 1 / (m s^2 + s + k) $, name: "w")
#where(($m$, [масса системы]), ($k$, [коэффициент жёсткости пружины]))
```

- У рисунка метка берётся из имени файла: `img/er-diagram.png` даёт
  `@er-diagram`. Другое имя: `name: "db"`.
- Ссылка выводит только номер, слово в нужном падеже пишется в тексте:
  `на рисунке @er-diagram` даёт «на рисунке 2.3», `уравнением @w` даёт
  «уравнением (3.1)», `в приложении @code` даёт «в приложении А».
- Номера идут в пределах раздела (`Рисунок 2.3`, `Таблица 1.1`, `(3.1)`), в
  приложениях с буквой (`Рисунок А.1`).
- Подпись рисунка по центру под ним, подпись таблицы над ней с абзацного
  отступа, длинные подписи не растягиваются.

## Код

```typst
// фрагмент до половины страницы в тексте, оформляется рисунком
#code-figure(path("src/Repository.cs"), [Метод сохранения договора])

// полный текст программы в приложении, Times 12 pt
#appendix([Листинг программы], name: "code")
#listing(path("src/Program.cs"))
```

Путь передаётся через `path(...)`: так файл ищется рядом с отчётом, а не
внутри пакета.

## Приложения и источники

```typst
По данным #src("date") ... в документации #src("mssql", page: 12) ...

#sources(
  date: [Дейт, К. Дж. Введение в системы баз данных / К. Дж. Дейт. – 8-е изд. – М. : Вильямс, 2006. – 1328 с.],
  mssql: [Документация по SQL Server / Microsoft. – Режим доступа: https://learn.microsoft.com/sql. – Дата доступа: 12.10.2026.],
)

#appendix([Листинг программы], kind: "обязательное", name: "code")
```

- `#src("key")` даёт «[1]», с `page:` даёт «[1, с. 12]». Список нумеруется по
  первой ссылке в тексте, источники без ссылок в него не попадают.
- Описания источников пишутся вручную по ГОСТ 7.1, примеры в методичке.
- Приложения обозначаются А, Б, В… без Е, З, Й, О, Ч, Ь, Ы, Ъ, каждое с новой
  страницы и попадает в содержание.

## Переход с 1.0

| 1.0 | 2.0 |
|---|---|
| `#show: standard-styles` + `#title-page(...)` | `#show: ghost.with(kind: "lab", ...)` |
| `#(pages.curse-title)(...)` | `#show: ghost.with(kind: "course", ...)` |
| `supervisor: "...", supervisorTitle: "..."` | `supervisor: ("...", "...")` |
| `course: "..."` | `discipline: [...]` |
| `#picture(image("a.png"), "Подпись", part: "А")` | `#picture(image("a.png"), [Подпись])`, буква приложения ставится сама |
| `#appendix-heading("Приложение А")` и `(обязательное)` вручную | `#appendix([Название])` |
| `\` для пустых строк вокруг заголовков | не нужны, отступы ставятся сами |
| свой `#set page(footer: ...)` с номерами | не нужен |
